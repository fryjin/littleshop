# Little Shop Visual Prototype

微信小程序商城高保真静态视觉稿，产品为德国手工香薰雕刻蜡烛。

## 当前交付

- 入口页：`mini-program-visual-prototype/index.html`
- 当前阶段：静态 HTML 视觉稿，不包含真实小程序、后端、支付、登录、库存或客服接口。
- 页面数量：24 个 HTML 页面，包含 `address.html`、`invoice.html`、`policy.html` 等账户基础能力页。
- 默认身份：零售买家；经典系列和渠道批发价仅在批发路径中出现。
- 视觉方向：Wax Atelier，手工奢品、礼品橱窗、克制交易、香氛生活方式、批发渠道可信感。

## 最新迭代

本轮更新聚焦零售导购、商品浏览、账户基础能力、价格阶梯和高客单场景收敛：

- 首页保留按场景、按预算、按节日和批发拿样入口；进阶场景区为定制、婚礼采购和搭配推荐，本周热卖按进阶 / 匠作 / 节日展示商品。
- 选礼页改为紧凑筛选流：预算、场景、节日三行横向条件，上方筛选即时刷新下方五个单列推荐商品；自定义预算用底部区间抽屉承接。
- 零售商品手册仅展示进阶、匠作和节日系列；顶部系列 tab 更紧凑，支持 `#advanced`、`#artisan`、`#festival` 和节日 hash 直达，并在切换后回到当前系列起点。
- 商品卡使用小型圆形 `+` 快速加购；进阶和匠作商品加购后停留当前页，节日商品进入详情页确认包装。
- 商品详情页支持多图轮播、紧凑尺寸 pill、香型、雕花弹窗大图预览、包装选择、阶梯价格表、底部加购 CTA 和底部导航；无香陈列不展示香调详情。
- 购物车定位为下单前配置检查，商品数量与本地加购角标同步，并按加购明细逐条展示不同商品，显示当前阶梯价、继续加购优惠提示、收货地址、跨境目的地下拉和配送售后说明。
- 我的页使用头像资产卡和渠道主入口；功能区顺序为地址管理、发票管理、客服售后、政策协议。
- 积分页改为积分总览：展示当前积分、累计记录、消费记录和积分商城入口；复购券页只展示可用优惠和领券中心，不混入商品推荐。
- 搭配推荐页提交后收起表单，直接展示三款推荐，推荐卡可直接加购；婚礼采购页支持多选使用场景、多款推荐和轻量 `+` 加购；定制页改为三步式配置。

## 核心页面

- `home.html`：首页分流、快捷入口、本周热卖和进阶场景。
- `gift.html`：零售选礼助手，按场景、预算和节日降低选择成本。
- `catalog.html`：零售商品手册，展示进阶、匠作、节日系列，并支持筛选和加购反馈。
- `product.html`：商品详情，展示轮播图、尺寸、香型、雕花弹窗预览、包装、购买参考信息和底部导航。
- `cart.html`：购物车与下单前配置确认，支持选择已有收货地址、同步加购数量、阶梯价提示和跨境目的地。
- `address.html`：地址管理，可设置默认地址、切换本地预览默认地址，并预留新增 / 编辑入口。
- `invoice.html`：发票管理，展示常用抬头、开票记录和开票说明。
- `policy.html`：政策协议，集中展示购买须知、售后说明、隐私协议和渠道申请说明。
- `wholesale.html` / `wholesale-catalog.html`：渠道申请、批发手册和顾问确认路径。
- `sample.html` / `quotation.html`：拿样包和渠道报价单。
- `custom.html` / `wedding.html` / `ai-match.html`：定制、婚礼采购和搭配推荐静态演示。

## 使用方式

直接在浏览器打开：

```text
mini-program-visual-prototype/index.html
```

本地开发预览可使用任意静态服务器指向 `mini-program-visual-prototype/`，例如：

```text
http://127.0.0.1:5174/index.html
```

静态页面共享：

- `mini-program-visual-prototype/assets/styles.css`
- `mini-program-visual-prototype/assets/app.js`

截图位于：

- `mini-program-visual-prototype/_screenshots/`
